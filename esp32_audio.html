本项目是一个多模式深度集成的嵌入式音频平台，以 ESP32-S3（Xtensa LX7 双核 240MHz）+ ES8388 Codec 为核心，实现网络电台 MP3 流播放、WiFi 声卡 UDP 透传、USB UAC2.0 声卡、SD 卡录音播放四大功能，四种模式互斥运行，共享 I2S/ES8388 硬件。GMF Pipeline 录音架构替代传统 RingBuffer 方案，Pipeline 复用避免内存碎片化。USB UAC2.0 描述符全面重构，解决 Windows 下 MIC+SPK 组合设备无声问题。

USB 声卡
UAC 2.0 · 描述符重构 · MIC 高通滤波 · NVS 音量
UAC2 TinyUSB IIR/FIR NVS
›
点击展开详情
架构
PC --USB--> UAC2 --output_cb--> RingBuf(64KB) --> I2S --> ES8388 ES8388 ADC --> I2S --input_cb--> mic_filter --> UAC2 --USB--> PC
描述符重构（关键修复）
  • bCategory 改 UNDEF(0x00)，避免 Windows 对 Headset 的特殊处理导致 MIC=1 时 SPK 无声
  • 双独立 Clock Source（SPK_CLOCK=0x01, MIC_CLOCK=0x05），Windows USBAudio2 驱动要求
  • MIC Input Terminal type 改 0x0201（物理麦克风），bmChannelConfig 改 FL+FR
  • SPK 改 Adaptive 模式（去掉 Feedback EP），节省 DWC2 FIFO 空间
  • DWC2 DFIFO 仅 200 words，16-bit/48kHz/2ch MIC+SPK 是唯一可靠配置
MIC 高通滤波器
  • IIR 双二阶（esp_ae_eq）：fc=100Hz, Q=0.707 Butterworth，CPU ~2%
  • FIR 64阶（Q15 定点）：窗函数法设计，先低通再互补得高通，CPU ~7%
  • 运行时串口切换：mic_filter none|iir|fir [cutoff_hz]
  • USB 声卡路径（input_cb）和录音路径（post_read_cb）双路集成
音量管理
  • UAC2 音量映射：-50dB~0dB → 0~100%，(int32_t) 修复负数转换 bug
  • NVS 持久化：保存 SPK 音量 raw 值，重启恢复，默认 -25dB(50%)
  • 16/24/32-bit + 1/2ch 全组合自适应，sdkconfig 配置无需改代码

PSRAM DMA SPI复用 Core0/Core1

PSRAM 内存规划
  • 音频工作缓冲区全部 heap_caps_malloc(PSRAM)，释放内部 RAM 压力
  • RingBuffer 显式分配 PSRAM：MP3 16KB + PCM 128KB + WiFi 64KB + USB 64KB
  • CONFIG_SPIRAM_MALLOC_ALWAYSINTERNAL=8192，小对象留内部 RAM
  • CONFIG_SPIRAM_MALLOC_RESERVE_INTERNAL=32768，保留 32KB 防挤占
  • BSS 段 + 任务栈可放 PSRAM，WiFi/LWIP 缓冲区自动分配至 PSRAM
SPI 总线复用
  • SPI2_HOST 被 LCD 和 SD 卡共用（SCLK=12, MOSI=11, MISO=13）
  • 仅 CS 不同（LCD=GPIO21, SD=GPIO2），spi_bus_initialize 返回 ESP_ERR_INVALID_STATE 时跳过
  • SD 卡 3 次重试 + 500ms 间隔 + 失败后 unmount 清理
双核任务分配
  • Core 0：WiFi/LWIP、HTTP 下载、I2S 输出、Web 服务器
  • Core 1：MP3 解码、GMF 录音 Pipeline、io_codec_dev、io_file
  • Console REPL 栈 4096→8192，httpd 栈 8192→12288
  • 分区表：factory 2MB + storage 7.44MB（固件 1.5MB 超出原 1.5MB 分区后扩容）

STM32F407 USB 声卡 (CherryUSB)
UAC2.0 · WM8978 · RingBuffer + Circular DMA · 预填充策略
CherryUSB UAC2 WM8978 DMA RT-Thread
›
点击展开详情
数据流架构
PC --USB ISO OUT--> CherryUSB --rb_put--> RingBuf(16KB) --预填充--> Circular DMA --> I2S2 --> WM8978 192B/ms 48k/16b/2ch ISO中断上下文 1920B(10ms)门槛 960样本循环缓冲 Half/Full回调
核心特性
  • CherryUSB v1.6.1 UAC2.0 Speaker，覆盖弱函数回调实现自定义逻辑
  • WM8978 Codec：17步初始化流程，I2C 7位地址+9位数据=16位写入，不支持读操作
  • 预填充策略：RingBuffer 积累满 1920 字节(≈10ms) 后才启动 DMA，避免空数据"嘟"声
  • Underrun 处理：数据不足时保持上次数据不填零，避免突变噪声
  • USB 音量映射：-60dB~0dB → 0~63 WM8978 音量等级
  • Circular DMA 双缓冲：Half/Full Complete 回调交替填充，零拷贝
踩坑记录
  • RT-Thread 内置 USB Audio 驱动 3 个 Bug：端点 bmAttributes 不匹配、AC Header wTotalLength 计算错误、SET_CUR 请求逻辑错误 → 改用 CherryUSB
  • CherryUSB 模板宏 PKG_CHERRYUSB_DEVICE_TEMPLATE_AUDIO_V2_MIC_SPEAKER 与自定义代码链接冲突(multiple definition) → 注释掉模板宏
  • BSP drv_usbd.c 与 CherryUSB DWC2 驱动都处理 USB OTG 中断 → board.h 注释 BSP_USING_USBDEVICE
  • HAL_I2S_TxCpltCallback 重复定义 → drv_audio_wm8978.c 中 #ifndef PKG_USING_CHERRYUSB 保护
  • rtconfig.h 被 RT-Thread Settings 覆盖：DWC2_ST 被改回 CUSTOM、模板宏被重新启用
