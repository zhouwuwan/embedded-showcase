点击展开详情
项目描述

统一管理多从站轮询调度的核心引擎。每个从站独立维护 libmodbus context、心跳线程和工作线程，通过消息队列接收控制指令（启动/停止/退出）。TCP 从站采用长连接 + 心跳保活策略，每 30 秒发送 FC03 请求维持连接活跃。轮询间隔可配置，支持运行时动态启停单个从站。

核心特性
  • mb_quick_start 一键初始化：3 行代码配置 3 个从站（TCP/RTU/WiFi）
  • 分层设计：添加从站无需修改定时器代码，slave_info 配置表驱动
  • TCP 长连接 + 心跳保活：30 秒一次 FC03 读 1 个寄存器，避免每次轮询重建连接
  • 消息队列驱动：poll_start/poll_stop/poll_exit 通过 rt_mq_send 异步控制
  • valid_mask 机制：连续地址存储，无效地址填 0 不报错，从站侧不操作 GPIO 便于广播写
  • 主从共用数据块结构：modbus_bits_block_t / modbus_regs_block_t 主从站都可复用
  • API 层解耦：WebNet 等消费者通过 poll_get_slave_info() 读取，不直接 extern 内部数据
  • poll_stop 安全退出：先删消息队列（使 rt_mq_recv 返回错误），等线程退出，再删线程
关键技术点
  • RT-Thread v5.x rt_mq_recv 返回值变更：成功返回消息字节数而非 RT_EOK，必须用 err < 0 判断
  • 双网卡路由：e0(192.168.0.100) + e1(192.168.3.100)，modbus-tcp.c 源 IP 绑定解决跨网段路由
  • 线程栈：心跳线程 4096 字节，工作线程 8192 字节（lwIP 调用链深度大）

项目描述

基于 RT-Thread WebNet 组件的 HTTP 接口层。CGI 模式注册 3 个端点：/cgi-bin/slaves（从站列表）、/cgi-bin/slave（单站详情）、/cgi-bin/write（写操作）。仪表盘 HTML 独立文件通过 FTP 上传至 /data/webnet/index.html（NAND Flash 持久化），编辑后 FTP 上传即可更新，无需重编固件。

核心特性
  • 3 个 CGI 端点：slaves（从站列表 JSON）、slave（单站详情 JSON）、write（写操作）
  • write 端点支持 fc 参数：fc=5 写线圈（FC05）、fc=6 写寄存器（FC06），默认 fc=6
  • 仪表盘 Linear Aesthetic 风格：2 秒 XMLHttpRequest 自动刷新，线圈点击翻转，寄存器点击编辑
  • 输入保护：寄存器值范围 0-65535，线圈仅 0/1 翻转
  • WebNet 根目录 /data/webnet（NAND Flash），重启不丢失，优于 /tmp/webnet（RAM）
  • HTML 独立部署：FTP 上传 dashboard.html 即可更新界面，不嵌入固件 C 字符串

STM32F407 双从站系统
RTU+TCP 双通道 · 共享数据区 · qmodbus SOCK 后端
STM32F407 qmodbus RTU TCP
›
点击展开详情
项目描述

STM32F407 同时运行 Modbus RTU 从站（站号 1，RS485 USART2）和 Modbus TCP 从站（站号 12，端口 502 SOCK 后端）。两个从站共享同一数据区，任一通道写入的数据另一通道也能读到，通过互斥锁保证并发安全。INIT_APP_EXPORT 自启动，上电即运行。

核心特性
  • RTU 从站：USART2 RS485（PD5/TX, PA3/RX），SP3485 方向控制 PG8，站号 1
  • TCP 从站：SOCK 后端，端口 502 侦听，accept 连接后创建从机实例，站号 12
  • 共享数据区：线圈 32 位 + 寄存器 32 个 + valid_mask，rt_mutex 保护
  • qmodbus 回调覆盖：mb_cb_table_t 覆盖弱函数，读写操作直接访问共享数据区
  • 从站侧不操作 GPIO：valid_mask 标记无效地址填 0 不报错，便于主机广播写
  • 静态 IP 192.168.3.30，禁用 DHCP，直连网段无需网关

项目描述

完整的 MSH 交互式命令行工具集，覆盖连接、读写、轮询调度全流程。支持 TCP/RTU 两种后端，开发调试阶段可逐步操作，生产环境可一键启动。

命令列表
  • mb_connect <ip> <port> [rtu|tcp] — 建立从站连接
  • mb_read <addr> <count> [bits|regs] — 读取线圈/寄存器
  • mb_write_reg <addr> <value> — 写单个寄存器（FC06）
  • mb_write_bit <addr> <value> — 写单个线圈（FC05）
  • mb_quick_start — 一键初始化 3 个从站并启动轮询
  • poll_start / poll_stop / poll_status — 轮询调度控制
  • mb_retry 宏：自动重连 + 重试，网络抖动容错
