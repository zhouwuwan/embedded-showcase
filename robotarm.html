项目概述
仿真实工业六轴机械臂的 3D 示教器，Qt 窗口左侧嵌入 RViz2 VisualizationFrame 实时渲染机械臂 3D 模型（Grid + RobotModel + MotionPlanning），右侧控制面板实现轴动（滑块设 6 关节角）、线动（末端 xyzrpy 位姿目标）、Home（回初始位置）三种运动模式。通过 MoveGroupInterface 下发规划目标，MoveIt2 自动完成 逆运动学（IK）求解 + 无碰撞轨迹规划 + 关节限位避让。tf2_ros 实时查询末端位姿同步到 UI，QThread 子线程处理 ROS2 回调避免阻塞 Qt 事件循环。

轴动（关节空间控制）
6 个滑块设 J1~J6 关节角 → MoveGroupInterface::setJointValueTarget + plan + execute
滑块范围 ±180°，点击"轴动执行"下发 6 关节目标（弧度），MoveIt2 在关节空间规划无碰撞轨迹并执行。开机自动校准滑块到当前关节角。
📏
线动（笛卡尔空间控制）
末端 xyz/roll/pitch/yaw → setPoseTarget + plan/move
6 个输入框设末端位姿，"线动规划"只 plan 在 RViz2 预览轨迹（不驱动机械臂），"线动执行"plan + execute 真正运动。MoveIt2 自动算 IK 解关节角。500ms 定时器通过 TF 实时同步末端位姿到输入框，用户编辑时自动暂停同步。
🏠
Home（回初始位置）
记录开机关节角 → sendJointGoal
开机时记录机械臂初始关节角到 m_initialJoints，Home 按钮发该目标（非硬编码 home 姿态），确保回到实际开机位置。
🔄
实时显示 + 开机校准
订阅 /joint_states → LCD 显示 + 滑块同步
QoS best_effort 订阅 /joint_states，按 UR5e 关节名（shoulder_pan_joint 等）匹配，弧度转角度显示。首次收到数据时同步滑块和线动输入框到当前姿态。
关键技术点
  • RViz2 嵌入 Qt：VisualizationFrame + RosNodeAbstraction 传入构造和 initialize，代码动态添加 4 个 display
  • 双 Node 分工：node_ 订阅 /joint_states + TF（rclcpp::spin 驱动）；move_node_ 给 MoveGroupInterface（move() 内部自 spin）
  • TF 查末端位姿：tf_buffer_->lookupTransform("base_link", "tool0") 替代 move_group_->getCurrentPose()（后者需 move_node_ 被 spin）
  • 互斥锁防死锁：std::atomic<bool> move_in_progress_ 防并发 move()（MoveGroupInterface 非线程安全）
  • 跨线程信号槽：qRegisterMetaType<QVector<double>> 注册元类型，QThread 子线程 emit 信号主线程槽函数
  • 析构顺序保证：delete MainWindow（含 rviz）在 rclcpp::shutdown 之前，避免访问已关闭 ROS2
踩坑记录（17 个）
订阅 /joint_states 阶段
  • CMakeLists 缺 install(TARGETS) → 编译成功但运行旧代码
  • 缺 set(CMAKE_AUTOMOC ON) → undefined reference to vtable
  • 缺 qRegisterMetaType → 信号被静默丢弃
  • 默认 RELIABLE QoS → VMware 收不到数据，改 best_effort
  • 关节名没匹配 UR5e → 显示错关节
  • DDS 多播延迟 → FASTDDS_LOCALHOST_EXECUTION=1
MoveIt2 集成阶段
  • CMake target 名少了 moveit_ 前缀
  • moveit::core::MoveResult 在 Jazzy 中不存在
  • plan() 需要传 Plan 参数
  • getCurrentPose() 返回全 0 → 改用 TF lookupTransform
  • 并发 move() 死锁 → std::atomic 互斥
  • 线动输入框被定时器覆盖 → m_poseEditing 标志
RViz2 嵌入阶段
  • Qt5/Qt6 冲突 → rviz 依赖 Qt5，改用 Qt5::Widgets
  • VisualizationFrame 构造需 RosNodeAbstraction 第一参数
  • initialize() 需两个参数，无零参重载
  • 设置 display 属性抛异常 → 用默认值
  • Node already added to executor → rviz 内部自 spin
